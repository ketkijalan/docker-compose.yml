BusyWork is a voice-first app that helps elderly people who live alone book a cab, order groceries and order medicines by speaking, with no typing. It understands Hindi, English and a mix of both.

The problem

Many senior citizens live alone and deal with weak eyesight, memory problems, nerve issues and slow speech. Everyday apps expect them to type addresses, search for items and remember passwords. For them, a simple cab booking can become impossible without help from someone else.

Our solution

Voice comes first because it is clear, fast and natural. The user taps one big button and speaks. BusyWork understands the request, repeats it back, and only goes ahead after the user says yes.

Features
Voice in Hindi, English or a mix. The language switches automatically when Hindi is spoken.
Cab, groceries and medicines. Say, for example, "Book a cab for Colaba, house 7".
Double confirmation. BusyWork confirms the request first, then asks again before any payment.
Slow, simple speech. Short sentences read at a slower pace.
Stay here please mode. If the user goes quiet mid-task, BusyWork repeats a reminder every 20 seconds.
Helpline fallback. After two misunderstandings or three reminders, a big call button appears (14567).
Remain with me. A 10-minute friendly chat for lonely moments.
Large buttons, minimal text. Yes and No buttons, quick-action buttons, and a typing box as a backup.
No secret keys. The app starts and shows its main screen without any API key. The chat feature shows "key not set" and uses simple built-in replies.
